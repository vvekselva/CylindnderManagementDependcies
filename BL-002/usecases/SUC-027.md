## Business purpose

SUC-027 gives an operator a read-only dashboard for tracing cylinder custody held by CUSTOMER or SUPPLIER parties. It supports investigation by party type, custody status, vehicle-trip identity, and cylinder/party search text while preserving the persisted custody identity and entry/exit trace.

## Entry and filter contract

The browser opens `GET /party-custody-traceability`. The request may contain `partyType`, `custodyStatus`, `tripId`, and `searchTerm`. The controller delegates the submitted values to `OwnershipObligationDashboardService.fetchDashboard`, preserves the selected values in the model, and renders the Party Custody Traceability dashboard.

The visible form supports CUSTOMER/SUPPLIER party filtering, ACTIVE/CLOSED custody filtering, a numeric trip ID, and serial/party text search. Filtering occurs by ordinary GET submission; no AJAX/debounce/dependent selector behavior is part of this Use Case.

## Source-proved read behavior

The service computes total active obligations, CUSTOMER-active count, SUPPLIER-active count, aging-active count, and obligations closed today. Party summaries are limited to the first 50 rows ordered by active count descending. Detail rows are limited to the first 200.

The detail read uses persisted party-custody data joined to cylinder/customer/supplier information. Null/blank filters mean all rows for that criterion. A supplied trip ID matches either entryTripId or exitTripId. Search text performs case-insensitive contains matching against cylinder serial or party name. Detail rows are ordered by custody ID descending.

## Identity and traceability

The durable detail identity is the custody record `pk_custody_id`. Each row exposes cylinder identity/serial, party type/name, custody status, entry trace, exit trace, and time/aging information. Entry/exit traces retain the available event, trip, load and stop identifiers rather than replacing them with inferred business meaning.

## Persistence and side effects

SUC-027 is read-only. It does not create, update, close, transfer or otherwise mutate cylinder custody. Any custody movement belongs to the operational transaction that created the underlying custody history.

## Error/boundary behavior to preserve in testing

- Omitted/blank party type means no party-type restriction.
- Omitted/blank custody status means no custody-status restriction.
- Null trip ID means no trip restriction.
- Blank search text means no search restriction.
- A non-convertible nonblank `tripId` cannot bind to the controller's Long parameter; no Story-specific graceful conversion-error page is source-proved.
- Empty result sets must remain a valid read outcome and must not cause a write or invented record.
- Aging is based on ACTIVE custody with a non-null aging-due timestamp older than the current database time.
- Closed-today counts are based on CLOSED custody whose exit date is the current database date.

## Candidate Use Case test scenarios

These scenarios are prepared for approval review only; they are not yet authoritative Use Case tests:

| Scenario | Given | When | Expected |
|---|---|---|---|
| UC027-01 | Active CUSTOMER and SUPPLIER custody exists | Dashboard opens with no filters | Aggregate metrics and detail rows are returned read-only. |
| UC027-02 | CUSTOMER custody exists | partyType=CUSTOMER | Only CUSTOMER detail rows are included. |
| UC027-03 | ACTIVE and CLOSED history exists | custodyStatus=ACTIVE | Only ACTIVE custody rows are included. |
| UC027-04 | Custody records have entry/exit trip IDs | tripId is supplied | Rows match when either entryTripId or exitTripId equals the supplied ID. |
| UC027-05 | Cylinder serial/party names contain mixed case | searchTerm is supplied | Case-insensitive serial/party-name matching is applied. |
| UC027-06 | Active custody is past agingDueAt | Dashboard metrics are calculated | Aging-active count includes the overdue active custody. |
| UC027-07 | Custody was closed today | Dashboard metrics are calculated | Closed-today count includes the matching record. |
| UC027-08 | No rows match the filters | Dashboard is requested | Valid empty/read-only result; no persistence mutation. |
